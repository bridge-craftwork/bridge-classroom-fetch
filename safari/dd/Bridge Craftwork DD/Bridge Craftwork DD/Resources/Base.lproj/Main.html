Getting started

  1. Turn the extension on in Safari’s settings, under Extensions.
  2. In Bridge Base Online’s web lobby, open History and an event you played.
  3. Click the extension’s button in Safari’s toolbar, choose Always Allow on Every Website, then reload the page. It still runs only on Bridge Base Online and Bridge Classroom.
  4. Each board you open marks the cards that cost a trick, and DD Details opens it in the detailed double-dummy viewer.

Until Safari allows it, the extension shows nothing, and its toolbar button is grey. You can also allow the sites in Safari’s settings: Extensions, then Edit Websites…
